# RefillTrack

INTPROG Final Project - Case Study 32: Water Refill Delivery Manager
Student: Nichole Kaye N. Orador (24248916) | BSITS SE - TTH 3:00 PM - 4:30 PM
 
RefillTrack is an Android app (Kotlin) that gives a water-refilling station one
organized list of delivery orders with a fixed status workflow:
Pending -> Preparing -> Out for Delivery -> Delivered (Cancelled only while Pending).
 
## Roles
- Staff: add orders, prepare, assign rider, cancel, search, view history
- Rider: view assigned orders, mark as Delivered
